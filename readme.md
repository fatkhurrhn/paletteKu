# 🎨 PaletteKu - Color Palette Community

PaletteKu is a modern web application where color enthusiasts can discover, share, and save beautiful color combinations. Built with React, Firebase, and Tailwind CSS.

## ✨ Features

### 🎯 Core Features
- **Discover Colors & Palettes** - Browse through thousands of colors and palettes from the community
- **Create & Share** - Add single colors or create multi-color palettes
- **Like & Engage** - Show appreciation for your favorite colors and palettes
- **View Counter** - Track how many people have viewed each color/palette
- **Public Profiles** - Every contributor has their own public profile showing their contributions

### 🔐 User Features
- **Google Authentication** - Easy login with Google account
- **Personal Dashboard** - Manage all your colors and palettes in one place
- **Profile Management** - Update your profile info, avatar (via Cloudinary), bio, and location
- **CRUD Operations** - Create, Read, Update, Delete your contributions

### 🎨 Color Tools
- **HEX to RGB/CMYK** - Automatic color conversion
- **Complementary Colors** - See matching colors
- **Color Shades** - View 10 different shades of any color
- **Copy to Clipboard** - One-click copy for any color code
- **Similar Colors** - Discover related colors from the database

### 📱 Responsive Design
- Fully responsive on all devices (mobile, tablet, desktop)
- Modern UI with smooth animations
- Dark/Light color scheme optimized

## 🚀 Tech Stack

### Frontend
- **React 18** - UI Framework
- **React Router DOM** - Navigation
- **Tailwind CSS** - Styling
- **Remix Icon** - Icons
- **Vite** - Build tool

### Backend & Database
- **Firebase Authentication** - User authentication
- **Firebase Firestore** - NoSQL database
- **Cloudinary** - Image upload & storage

### Development
- **ESLint** - Code linting
- **PostCSS** - CSS processing
